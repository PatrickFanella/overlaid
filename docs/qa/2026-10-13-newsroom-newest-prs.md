- PostgreSQL tests with independent Store instances admitted one concurrent review claimant, one revision-zero editor, and one show starter. Bundle creation admitted both idempotent callers with one retained bundle; revision-zero bundle edits admitted one winner. Viewer deletion also removed detached bundle context. Cross-tenant search and show exports were refused/empty as appropriate.
- Regressions cover expiry, stale renewal/release tokens, owner release permissions, legacy writes under claims, metadata versus editorial changes, stale Undo, cursor paging over 256 items with a tied nanosecond timestamp and a newer head insert, literal wildcard characters, title/publisher/topic filters, show restart persistence, immutable rundown/history, recording URL validation, export independence, and viewer deletion from detached show snapshots.
- The browser loaded all 255 synthetic pending items over six pages, combined title and media filters, and exercised Start/Extend/Release and Reject/Undo. Switching filters removed the previous rows from action eligibility.
- Browser show flow: start → focus → edit notes → Played → end → recording URL/offset → Markdown and chapter downloads. The rendered chapter export and story links included the saved recording offset. Repeated exports produced the same chapter text.
- Browser stale-draft flow: a competing editorial write caused a warning save to return 409. The warning draft survived reload. Explicit reconciliation retained that warning and preserved the competing editor's untouched takeaway.
- Browser QA found and corrected blur/autosave action timing: the note save no longer disables the Played click, and all save callers wait for local revision bookkeeping before submitting Played. The final API trace showed edit followed by play with the incremented revision, both HTTP 200.
- Desktop and 375px layouts had no horizontal overflow in queue/reaction and show/recording views.

- Bundle regressions cover duplicate creation, role/URL/count validation, competing edits, stable pagination, file restart, lead deletion, and immutable start versus play context. Evidence regressions cover transcript/description/post/page labels, observed social fallback retrieval, rune-based input bounds, refused/malformed/empty AI output, and original evidence preservation after metadata refreshes.

The downloaded Markdown retained play prep and the starting rundown retained starting prep; neither contained the later edit.
